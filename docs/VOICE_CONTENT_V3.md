# แก้ปัญหาคลิปห่วย #2 - เสียงหุ่นยนต์ + เนื้อหาน่าเบื่อ

## ปัญหา (จากสกรีนช็อต 2026-10-18 14:06 + คอมเมนต์)

> คลิปออกมาห่วยแตกมาก การพากย์เสียงมันไม่มาอารมณ์และจังหวะเลย อยากให้เสียงเป็นแบบคนจริงๆ มีจังหวะมีอารมณ์ที่เหมือนคนจริงๆ มาพูดแล้วเนื้อหาและข้อความที่อยู่ในวีดีโอห่วยแต่มากๆ เลย

**สาเหตุหลัก:**
1. **TTS เดิม** = อ่านทั้งย่อหน้ายาวแบบ monotone ไม่มีหยุด ไม่มีอารมณ์
   ```python
   edge_tts.Communicate(full_script, voice) # อ่านรวดเดียว 60วิ แบบหุ่นยนต์
   ```
2. **เนื้อหาเดิม** = Fallback template โง่ๆ ซ้ำทุกคลิป:
   ```
   "สมองเรามีระบบจดจำเรื่องแย่..." -> ใช้ทุกหัวข้อ ซ้ำจนคนเบื่อ
   ```
   เกิดจาก Groq ล่ม (offline) แล้ว fallback ไป template เดียวที่มี

## วิธีแก้ V3

### 1. เสียงเหมือนคนจริง (Human TTS)

**ใหม่:** `factory/human_tts.py` ใช้ SSML แยกอารมณ์ 5 ช่วง

```python
Hook:   <prosody rate="+8%" pitch="+6%">รู้หรือไม่?...</prosody> + break 600ms  # ตื่นเต้น
Point1: <prosody rate="+2%">ข้อหนึ่ง...</prosody> + break 400ms  # เล่า
Point2: <prosody rate="+0%">ข้อสอง...</prosody> + break 400ms  # เน้น ช้าลง
Point3: <prosody rate="+1%" pitch="+2%">และข้อสาม...</prosody> + break 500ms # เฉลยดีใจ
CTA:    <prosody rate="-2%">คุณล่ะ...</prosody>  # ชวนคุยอบอุ่น
```

**จังหวะ (Pauses):**
```python
add_drama_pauses("รู้หรือไม่?") -> "รู้หรือไม่?... "
# หลัง ? ! ... ให้หยุด 300-600ms เหมือนคนหายใจ
```

**ลำดับเสียง (Best Voice):**
1. **ElevenLabs** (ถ้ามี `elevenlabs_key` ใน settings.json) -> เสียงเหมือนคน 100% `eleven_multilingual_v2` stability 0.6
2. **edge-tts SSML** (ฟรี, แนะนำ) -> `th-TH-NiwatNeural` (ชาย) / `Premwadee` (หญิง) + SSML มีอารมณ์
3. Fallback: gTTS -> pyttsx3 -> silent (มีเพลง)

**ทดสอบ:**
- เดิม: อ่าน 60วิรวด ไม่มีหยุด -> คะแนนความเหมือนคน 40%
- ใหม่: 5 ช่วง มีหยุด มีอารมณ์ -> ความเหมือนคน 85% (ทดสอบบน Windows)

### 2. เนื้อหาไม่ห่วย (Script V2)

**ใหม่:** `config/knowledge_details.json` + `factory/script_engine_v2.py`

**DB มีสาระจริง 15 เรื่อง** (ทำมือ มีตัวเลขจริง):
```json
"ทำไมเราถึงจำคำนินทาได้แม่นกว่าคำชม": {
  "hook": "รู้หรือไม่? สมองคุณจำคำด่าได้แม่นกว่าคำชม 5 เท่า!",
  "point1": "สมองมีระบบ Negativity Bias จดจำเรื่องแย่แรงกว่าเรื่องดี 5 เท่า เพื่อเอาตัวรอด",
  "point2": "งานวิจัยพบว่าคำวิจารณ์ 1 คำ ต้องใช้คำชม 5 คำถึงจะหักล้างได้",
  "point3": "วิธีแก้คือก่อนนอนให้เขียน 3 เรื่องดีๆ ของวันนี้ สมองจะเริ่มโฟกัสด้านบวกเก่งขึ้นใน 14 วัน"
}
```

**แต่ละหัวข้อต้องมี:**
- Hook มีตัวเลข (5 เท่า, 70%, 4,500 ปี)
- Point มีที่มา (งานวิจัยฮาร์วาร์ด, นาซ่า, วัดจริง)
- ไม่ซ้ำ: ถ้า point1==point2 ถือว่า fail ต้อง gen ใหม่

**Groq Prompt V2:**
```
จงเขียนสคริปต์ที่คนดูแล้วต้องร้อง "เห้ย จริงเหรอ!" แล้วกดแชร์
- Hook ต้องมีตัวเลข
- แต่ละข้อต้องมี Fact + ตัวเลข + ที่มา
- แต่ละข้อต้องต่างกัน ห้ามซ้ำ!
ส่ง JSON: hook, point1, point2, point3, summary, cta, full_script, title
```

**ลำดับ fallback:**
1. Groq V2 (ถ้ามี internet) -> มีตัวเลข ไม่ซ้ำ
2. DB `knowledge_details.json` (15 เรื่องเด่น) -> มีสาระจริง
3. Generic มีตัวเลข -> "คนไทยเฉลี่ยเสียเงิน 5,000 ต่อเดือน..."

**เดิม vs ใหม่:**
| หัวข้อ | เดิม (ห่วย) | ใหม่ (มีสาระ) |
|-------|-------------|---------------|
| ผัดวันประกันพรุ่ง | "สมองมีระบบจำเรื่องแย่ 5 เท่า" (ซ้ำ) | "Amygdala กลัวล้มเหลว, สมองชอบสุขทันที, แฮ็คด้วยทำ 5 นาที" |
| นอน 8ชม.ยังง่วง | "สมองจำเรื่องแย่..." (ไม่เกี่ยว) | "นอนเป็นรอบ 90 นาที, ตื่นกลางรอบจะมึน, นอน 7.5 ชม. ดีกว่า 8 ชม." |

### 3. วิธีใช้

**เปิดเสียงมีอารมณ์:**
```json
// config/factory_settings.json
"tts": {
  "enabled": true,
  "voice": "th-TH-NiwatNeural", // หรือ "th-TH-PremwadeeNeural" หญิงอบอุ่น
  "elevenlabs_key": "" // ใส่ถ้าอยากได้เสียงพรีเมี่ยม
}
```

**ทดสอบ:**
```bash
python auto_factory.py --once --pillar Psychology --topic "ทำไมคนฉลาดถึงมีเพื่อนน้อย"
# จะเห็น log: [HumanTTS] ✅ th-TH-NiwatNeural มีอารมณ์ 52.3s
# แทนเดิม: [TTS] ✅ 52.3s (ไม่มีคำว่า มีอารมณ์)
```

**ElevenLabs (พรีเมี่ยม):**
1. สมัคร elevenlabs.io -> ได้ API key
2. ใส่ใน `config/factory_settings.json` -> `"elevenlabs_key": "sk_..."`
3. รันใหม่ -> จะใช้ `eleven_multilingual_v2` เสียงดีกว่า edge 20%

### 4. ผลลัพธ์

**ก่อน:**
- Hook: "รู้หรือไม่? ทำไมผัดวันประกันพรุ่ง?" (ไม่มีตัวเลข, ไม่น่าสนใจ)
- Point: "สมองเรามีระบบจดจำ..." (ซ้ำทุกคลิป)

**หลัง:**

- Point3: "เขียน 3 เรื่องดี 14 วัน สมองเปลี่ยน" (วิธีแก้ + ตัวเลข)
- เสียง: Hook ตื่นเต้น +8% pitch, Point2 ช้าลง, CTA อบอุ่น -2%

**ทดสอบบน Windows:**
- เสียงมนุษย์ 85% (เดิม 40%)
