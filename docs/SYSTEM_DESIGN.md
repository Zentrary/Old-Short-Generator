## 1. สมองหาเรื่อง (Topic Brain)

**ไฟล์:** `config/knowledge.json`

มี 4 เสาหลัก:
- 🧠 จิตวิทยา (จันทร์, พฤหัส) - คนดูเยอะสุด
- 💰 เงิน (อังคาร, ศุกร์) - สปอนเซอร์เข้า
- 🏥 สุขภาพ (พุธ, เสาร์) - ดูจบสูง
- 🏛️ ประวัติศาสตร์ (อาทิตย์) - แชร์เยอะ

**ระบบสุ่ม:**
- ดูวันนี้วันอะไร → เลือกเสาหลักตามตาราง
- สุ่มหัวข้อจาก 10 หัวข้อของเสานั้น ที่ยังไม่เคยทำ
- ถ้าหมด 10 หัวข้อ → ให้ Groq คิดหัวข้อใหม่ให้ 10 หัวข้อ

**กันซ้ำ:** เช็ค `outputs/logs/history.json` ว่าหัวข้อนี้เคยทำแล้วหรือยัง

## 2. เขียนบท 60 วิ (Script Engine)

**ไฟล์:** `factory/script_engine.py`

**สูตรตายตัว 60 วิ:**
```
0-3วิ: HOOK คำถามแรง (ต้องมี "รู้หรือไม่?" + ตัวเลข)
3-48วิ: เนื้อหา 3 ข้อ (ข้อละ 12-15วิ)
48-57วิ: สรุป 1 ประโยค
57-60วิ: CTA ชวนคอมเมนต์ (คอมเมนต์เลข 1/2)
```

**Prompt สั่ง Groq:**
```
เขียนสคริปต์ "รู้หรือไม่?" 60วิ ภาษาไทย
หัวข้อ: {topic}
หมวด: {pillar}
กฎ:
- เปิดด้วยคำถามชวนสงสัย 1 ประโยค ห้ามเกิน 15 คำ
- เนื้อหา 3 ข้อสั้นๆ แต่ละข้อมี "ทำไม" + คำอธิบายวิทยาศาสตร์ 1 ประโยค
- ปิดด้วยคำถามชวนคนดูคอมเมนต์
- ห้ามมั่วข้อมูล ถ้าไม่แน่ใจให้ใช้คำว่า "นักวิจัยพบว่า"
- ส่งกลับเป็น JSON: {"hook": "...", "body": "...", "cta": "...", "full_script": "..."}
```

**Fallback:** ถ้า Groq ล่ม → ใช้ Template สำรองในเครื่อง ไม่ให้โรงงานหยุด

## 3. พากย์เสียง (TTS Engine)

**ไฟล์:** `factory/tts_engine.py`

- ใช้ `edge_tts` เสียง `th-TH-NiwatNeural` (ผู้ชาย น่าเชื่อถือ)
- อ่าน `full_script` ทั้งหมด
- วัดความยาวเสียง → ถ้าเกิน 62วิ → สั่ง AI ย่อบทให้สั้นลง
- ถ้าสั้นกว่า 50วิ → ให้ AI เติมรายละเอียดเพิ่ม
- บันทึกเป็น `outputs/knowledge/audio/{date}_{topic}.mp3`

**ตั้งค่าใน `factory_settings.json`:**
```json
"tts": {"enabled": true, "voice": "th-TH-NiwatNeural"}
```

## 4. หาภาพพื้นหลัง (Media Engine)

**ไฟล์:** `factory/media_engine.py`

- ใช้ `Pexels API` และ `Pixabay API` ที่มีใน `settings.json` อยู่แล้ว
- ค้นหาด้วย `search_keywords` ของแต่ละเสา
  - จิตวิทยา → "psychology brain"
  - เงิน → "money finance"
  - สุขภาพ → "healthy lifestyle"
  - ประวัติศาสตร์ → "history ancient"
- ดาวน์โหลดวิดีโอแนวตั้ง 3-4 คลิปมาต่อกันให้ครบ 60วิ
- ถ้าไม่มีเน็ต/หาไม่เจอ → ใช้วิดีโอสำรองใน `assets/backgrounds/Knowledge_*`

**Auto-download:** ถ้าโฟลเดอร์ว่าง → ดาวน์โหลดอัตโนมัติตอนตี 5

## 5. ตัดต่อ+ซับ (Renderer)

**ไฟล์:** `factory/renderer.py`

Reuse โค้ดจาก `main.py` ทั้งหมด:
- `thai_wrap_px()` - ตัดคำไทยไม่ให้หลุดจอ
- `draw_thai_text()` - วาดสระวรรณยุกต์ไทยไม่ลอย
- `generate_text_overlay_image()` - ทำกล่องข้อความ
- `apply_video_effects()` - ฟิลเตอร์ Darken

**เลย์เอาต์ใหม่สำหรับความรู้:**
```
┌─────────────────┐
│  🔥 HOOK (บน) 15% │  → กล่องสีส้ม ตัวหนา "รู้หรือไม่?"
│                 │
│  📖 เนื้อหา 3ข้อ 55%│  → กล่องดำโปร่ง 3 บรรทัด กลางจอ
│                 │
│  👤 ช่อง (ล่าง) 85%│  → โลโก้ช่องจางๆ
│  ━━━ progress bar ━━━ │
└─────────────────┘
```

- ซับคำต่อคำเด้งตามเสียง (Word-by-word) ถ้า TTS เปิด
- เลขข้อ 1,2,3 ตัวใหญ่ๆ สีตามหมวด (จิตวิทยา=ม่วง, เงิน=เขียว)

## 6. ทำปก+ชื่อเรื่อง (Metadata Engine)

**ไฟล์:** `factory/metadata_engine.py`

**ชื่อคลิปสูตร:** `[Hook] | [หมวด] 1 นาที`
เช่น: `ทำไมคนฉลาดถึงมีเพื่อนน้อย? | จิตวิทยา 1 นาที #รู้หรือไม่`

**คำอธิบายสูตร:**
```
{hook}

📌 สรุปในคลิป:
1. {ข้อ1}
2. {ข้อ2}
3. {ข้อ3}

คุณเป็นแบบไหน? คอมเมนต์บอกหน่อย 👇

#รู้หรือไม่ #จิตวิทยา #ความรู้1นาที #shorts
```

**ปก Thumbnail (16:9 + 9:16 สองแบบ):**
- พื้นหลังเบลอจากวิดีโอ
- คำสั้นๆ 3 คำ เช่น "ทำไมฉลาด=เหงา?"
- สีตามหมวด + อิโมจิ

## 7. เรนเดอร์วิดีโอ (Factory Orchestrator)

**ไฟล์:** `factory/auto_factory.py`

**โฟลว์ 1 คลิป:**
```python
topic = brain.pick_topic(today)
script = script_engine.write(topic)
audio = tts_engine.speak(script.full_script)
videos = media_engine.fetch(topic.pillar, duration=60)
metadata = metadata_engine.build(script, topic)
output = renderer.render(videos, audio, script, metadata)
```

**Batch 3 คลิป/วัน:**
- รันลูป 3 รอบ → ได้ 3 ไฟล์ใน `outputs/knowledge/`
- แต่ละไฟล์ชื่อ: `20251018_073000_จิตวิทยา_ทำไมฉลาดถึงเหงา.mp4`
- บันทึก log ใน `outputs/logs/history.json`

---

## 8. ตั้งเวลาลง (Scheduler)

**ไฟล์:** `factory/scheduler.py`

Reuse `ScheduleManager` จาก `main.py`

- อ่าน `factory_settings.json` → `schedule_times: ["07:30", "19:30"]`
- สร้างแผน 30 วันใน `config/schedule.json`
- ถ้า `auto_upload: false` → แค่ตั้งเวลาไว้ รอคุณกด "เริ่มโพสต์" เอง
- ถ้า `auto_upload: true` → ตั้ง Cron ให้รัน `uploader.py` ตามเวลา

**ตารางตัวอย่าง:**
- ทุกวัน 07:30 = จิตวิทยา/เงิน (คนตื่นไถ)
- ทุกวัน 19:30 = สุขภาพ/ประวัติศาสตร์ (คนเลิกงาน)

## 9. วิเคราะห์ย้อนกลับ (Analytics)

## วิธีรัน

**รันมือ (ทดสอบ):**
```bash
python auto_factory.py --once --pillar Psychology
```

**รันออโต้ทุกวัน (ตั้ง Task Scheduler):**
```bash
python auto_factory.py --daily --batch 2
```

**รันพร้อมอัพโหลด:**
```bash
python auto_factory.py --daily --upload
```

## สิ่งที่ต้องเตรียมก่อนรันครั้งแรก

1. ใส่ `groq_api_key` ใน `config/settings.json` (มีแล้ว)
2. ใส่ `pexels_key` / `pixabay_key` (มีแล้ว)
3. โหลดวิดีโอพื้นหลัง 5-10 คลิป/หมวด หรือให้ระบบโหลดให้
4. ติดตั้งฟอนต์ไทย `NotoSansThai-Black.ttf` ใน `assets/fonts/` (ถ้ายังไม่มี)
5. ทดสอบรัน `--once` ดู 1 คลิปก่อน
